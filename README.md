Análisis de Siniestralidad Vial - Calarcá (2017-2022)
Proyecto de procesamiento de datos masivos (Batch) utilizando
Apache Spark (PySpark). El script realiza la limpieza,
transformación y análisis exploratorio sobre el conjunto de
datos abierto wacd-xkg8. Para ejecutarlo en un entorno
Linux/Ubuntu: spark-submit spark_batch_accidentes.py
